# 🐄 Kauã Bevilacqua - Bovinocultura de Leite

Projeto de um blog sobre **bovinocultura de leite**, desenvolvido utilizando HTML, CSS e JavaScript.

## 📚 Sobre o projeto

O site apresenta informações sobre temas relacionados à produção de leite e criação de bovinos, como:

- Alimentação do gado leiteiro
- Produção de leite
- Manejo do rebanho
- Bem-estar animal
- Genética
- Importância da água

O projeto possui um layout simples, responsivo e baseado em cartões (`article`), utilizando principalmente as cores azul e branco.
